## ตั้งต้นและเข้าสู่ระบบ

### BE-01 · ตั้งโปรเจกต์ Go Fiber + เชื่อม PostgreSQL

สร้างโครงโปรเจกต์ Fiber อ่านค่าจาก `.env` และเชื่อม PostgreSQL ด้วย GORM

**เกณฑ์เสร็จ**

- [x] `GET /api/health` ตอบ 200
- [x] ถ้าต่อฐานข้อมูลไม่ได้ แอปหยุดทำงานพร้อมข้อความบอกสาเหตุ
- [x] error ทุกตัวตอบเป็น JSON รูปแบบเดียวกัน `{"code": "...", "message": "..."}`

**รันในเครื่อง**

1. คัดลอก `.env.example` เป็น `.env`
2. เปิด PostgreSQL ด้วย `docker compose up -d postgres` หรือแก้ค่าเชื่อมต่อใน `.env` ให้ตรงกับฐานข้อมูลที่มีอยู่
3. รัน API ด้วย `go run ./cmd/api`
4. ตรวจสอบด้วย `GET http://localhost:8080/api/health`

### BE-02 · สร้างตารางฐานข้อมูล + ข้อมูลเริ่มต้น

ตาราง users, divisions, user_divisions, academic_years, topics, topic_fields, submissions, files

ต้องทำก่อน: BE-01

**เกณฑ์เสร็จ**

- [x] migration รันบนฐานข้อมูลว่างได้
- [x] มีข้อมูล 4 ฝ่าย (วิชาการ งบประมาณ บุคคล ทั่วไป) และปีการศึกษาปัจจุบัน
- [x] มีคำสั่งสร้างแอดมินคนแรก
- [x] คำตอบ 1 คนต่อ 1 หัวข้อ (unique topic_id + user_id)

**คำสั่งฐานข้อมูล**

รัน migration และข้อมูลตั้งต้น (รันซ้ำได้):

```powershell
go run ./cmd/migrate
```

สร้างแอดมินคนแรก โดยส่งรหัสผ่านผ่าน environment variable เพื่อไม่ให้ติดใน command history:

```powershell
$env:INITIAL_ADMIN_PASSWORD = "sdms-admin!"
go run ./cmd/create-admin -username admin -name "ผู้ดูแลระบบ" -position "ผู้ดูแลระบบ"
Remove-Item Env:\INITIAL_ADMIN_PASSWORD
```

### BE-03 · Login / Logout / Me

`POST /api/auth/login` · `POST /api/auth/logout` · `GET /api/me`

ต้องทำก่อน: BE-02

**เกณฑ์เสร็จ**

- [x] username + password ถูก → ได้ session cookie (HttpOnly)
- [x] รหัสผิดหรือไม่มีผู้ใช้นี้ → 401 ข้อความเดียวกันทั้งสองกรณี
- [x] บัญชีที่ปิดใช้งานแล้วเข้าระบบไม่ได้
- [x] รหัสผ่านเก็บเป็น hash (bcrypt)
- [x] `/api/me` คืนชื่อ ตำแหน่ง บทบาท ฝ่ายที่สังกัด และฝ่ายที่เป็นหัวหน้า

### BE-04 · Middleware ตรวจ login และสิทธิ์

ทำ middleware ตรวจ login และฟังก์ชันตรวจสิทธิ์ตามบทบาท (ครู · หัวหน้าฝ่าย · ผู้บริหาร · แอดมิน) ให้ทุก API ใช้ชุดเดียวกัน

ต้องทำก่อน: BE-03

**เกณฑ์เสร็จ**

- [ ] ไม่ login → 401 · ไม่มีสิทธิ์ → 403
- [ ] สร้างและแก้หัวข้อได้เฉพาะหัวหน้าฝ่ายนั้นกับแอดมิน
- [ ] คนที่ดูคำตอบทุกคนในหัวข้อลับได้ คือผู้บริหาร หัวหน้าฝ่ายนั้น และคนสร้างหัวข้อ
- [ ] คนที่ดูสถิติฝ่ายได้ คือผู้บริหารกับหัวหน้าฝ่ายนั้น
- [ ] มี unit test ครบทุกกฎข้างบน

## หัวข้อและฟอร์ม

### BE-08 · API สร้างหัวข้อ + ช่องฟอร์ม

`POST /api/topics`

ต้องทำก่อน: BE-04

**เกณฑ์เสร็จ**

- [ ] สร้างได้เฉพาะหัวหน้าฝ่ายนั้นกับแอดมิน
- [ ] รับชื่อหัวข้อ กำหนดส่ง ลับ/ไม่ลับ และรายการช่อง (ชนิด ชื่อ ต้องกรอกหรือไม่ ตัวเลือก ลำดับ)
- [ ] ช่องมี 6 ชนิด: ข้อความ ข้อความยาว ตัวเลข วันที่ ตัวเลือก ไฟล์
- [ ] หัวข้อผูกกับปีการศึกษาปัจจุบันอัตโนมัติ
- [ ] ชื่อว่าง หรือช่องตัวเลือกมีน้อยกว่า 2 ข้อ → 400 บอกว่าช่องไหนผิด

### BE-09 · API แก้ / ปิดรับ / เปิดรับ / ลบหัวข้อ

`PATCH /api/topics/{id}` · `POST /api/topics/{id}/close` · `POST /api/topics/{id}/reopen` · `DELETE /api/topics/{id}`

ต้องทำก่อน: BE-08

**เกณฑ์เสร็จ**

- [ ] แก้ได้เฉพาะหัวหน้าฝ่ายนั้น แอดมิน และคนสร้างหัวข้อ
- [ ] เปลี่ยนชนิดช่องเดิมหลังมีคนส่งแล้ว → 409
- [ ] ลบช่องที่มีคำตอบแล้ว = ซ่อนช่องนั้น ข้อมูลยังอยู่
- [ ] ลบหัวข้อที่มีคนส่งแล้ว → 409

### BE-10 · API รายการฝ่ายและหัวข้อ

`GET /api/divisions` · `GET /api/divisions/{code}/topics?year=`

ต้องทำก่อน: BE-08

**เกณฑ์เสร็จ**

- [ ] หัวข้อที่เปิดรับอยู่ขึ้นก่อน เรียงตามกำหนดส่งที่ใกล้ที่สุด หัวข้อที่ปิดรับแล้วอยู่ท้าย
- [ ] แต่ละหัวข้อบอกจำนวนส่งแล้ว x/y และสถานะของฉัน
- [ ] y = คนที่สังกัดฝ่ายนั้น ไม่รวมผู้บริหารและคนที่ปิดใช้งาน
- [ ] ถ้าไม่ส่ง `year` มา ใช้ปีปัจจุบัน

## ส่งเอกสารและไฟล์

### BE-11 · เชื่อม Google Drive + อัปโหลดไฟล์

`POST /api/uploads` · `DELETE /api/uploads/{id}`

ต้องทำก่อน: BE-04

**เกณฑ์เสร็จ**

- [ ] อัปโหลดทีละไฟล์ แล้วคืน file id ให้ FE แนบไปตอนส่งคำตอบ
- [ ] ไฟล์ใหญ่เกิน 50 MB → 413
- [ ] ไฟล์ไปอยู่ใน Google Drive ของโรงเรียน แยกโฟลเดอร์ตาม ปี / ฝ่าย / หัวข้อ
- [ ] ไฟล์ที่อัปโหลดแล้วแต่ไม่ได้ส่งภายใน 24 ชั่วโมงถูกลบอัตโนมัติ
- [ ] ตอนพัฒนาใช้โฟลเดอร์ในเครื่องแทน Drive ได้ (สลับด้วยค่าใน `.env`)

### BE-12 · API ส่ง / แก้คำตอบ

`GET /api/me/pending` · `GET /api/topics/{id}/my-submission` · `PUT /api/topics/{id}/my-submission`

ต้องทำก่อน: BE-08, BE-11

**เกณฑ์เสร็จ**

- [ ] `me/pending` คืนหัวข้อที่เปิดรับอยู่และฉันยังไม่ส่ง เรียงตามกำหนดส่ง
- [ ] ส่งได้เฉพาะคนที่สังกัดฝ่ายของหัวข้อ และหัวข้อต้องยังเปิดรับอยู่
- [ ] ช่องที่ต้องกรอกว่าง หรือค่าไม่ตรงชนิด → 400 บอกทีละช่อง
- [ ] ส่งซ้ำ = แก้คำตอบเดิม วันที่ส่งครั้งแรกไม่เปลี่ยน
- [ ] ส่งครั้งแรกหลังวันกำหนดส่ง (ตามเวลาไทย) → สถานะ "ช้า"

### BE-13 · API ตารางคำตอบของหัวข้อ

`GET /api/topics/{id}?status=` · `GET /api/topics/{id}/pending-names`

ต้องทำก่อน: BE-12

**เกณฑ์เสร็จ**

- [ ] คืน 1 แถวต่อผู้ต้องส่ง พร้อมค่าทุกช่อง ไฟล์ และวันที่ส่ง
- [ ] สถานะมี 5 แบบ: ส่งแล้ว · ช้า · ยังไม่ส่ง · เลยกำหนด · ไม่ส่ง (ปิดรับแล้ว)
- [ ] กรองด้วย `status=done` หรือ `status=pending` ได้
- [ ] หัวข้อลับ: คนที่ไม่มีสิทธิ์เห็นแค่แถวของตัวเอง
- [ ] `pending-names` ใช้ได้เฉพาะคนที่แก้หัวข้อนั้นได้

### BE-14 · API เปิดดู / ดาวน์โหลดไฟล์

`GET /api/files/{id}`

ต้องทำก่อน: BE-11, BE-13

**เกณฑ์เสร็จ**

- [ ] ตรวจสิทธิ์แบบเดียวกับตารางคำตอบ ไม่มีสิทธิ์ → 403
- [ ] PDF และรูปเปิดในเบราว์เซอร์ได้ ไฟล์ชนิดอื่นให้ดาวน์โหลด
- [ ] ดึงไฟล์จาก Drive แบบสตรีม ไม่แชร์ลิงก์ Drive ให้ผู้ใช้ตรง ๆ
